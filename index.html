    把一張圖片變成可探索的導覽

    圖片互動標記是放在圖上的可點擊按鈕，可以顯示說明、細節照片及連結。你可以為產品標出功能，替室內空間加入房間介紹，或把網站操作拆成依序瀏覽的步驟。

    上傳圖片後，選擇「新增互動點」並點擊圖上的位置。完成內容與樣式後，切換預覽確認效果，再匯出完整 HTML 或複製網站嵌入碼。

    常見問題

    如何放到 WordPress？

    可在允許指令碼的 Gutenberg 自訂 HTML 區塊貼上嵌入碼。若網站移除指令碼，請先將下載的 HTML 部署到 HTTPS 網址，再使用匯出區的 iframe 產生器。

    手機可以編輯嗎？這個工具免費嗎？

    可以。手機上可點選、拖曳和編輯標記，並切換不同裝置寬度預覽。工具免費使用。

    圖片會上傳嗎？

    本機圖片與專案留在目前瀏覽器。輸入的遠端圖片會連線至圖片主機。可下載 JSON 備份以便換裝置或移轉瀏覽器。
